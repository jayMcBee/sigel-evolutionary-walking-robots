# DELIBERATE DIVERGENCE, 2026-09-02: 1.3 has a SECOND About here, on the
# MetaGP menu ('&MetaGP | A&bout'), preceded by a separator, wired to the
# same slotAbout() as Help > About and opening the identical InfoBox. It was
# verified present in the running 1.3 binary and then REMOVED BY DECISION,
# separator included. Those two lines are absent below on purpose; this is
# the one place this baseline intentionally does not match 1.3. See C10.
#
# Structural dump of the ported master GUI: every menu entry and toolbar
# button, with shortcut, enabled state and check state.
#
# The 42 menu entries the SIGEL 1.3 oracle reported from the RUNNING 1.3
# binary were diffed against this file mechanically on 2026-08-31: zero
# mismatches, including the duplicate Ctrl+Shift+L on both Language-
# Parameters and Individual, the Import/Export asymmetry (Import has Robot,
# Export has ...to GNU plot), Reset being Alt+O rather than Alt+R, the
# Import and Export SUBMENU PARENTS staying enabled while every child is
# greyed, and Evaluator System showing its tick while greyed. The toolbar
# order (New, Delete, Open, Save, Quit -- Delete second, unlike the File
# menu) and the short iconTexts (Language, Genetic) were confirmed too.
#
# So this is not a snapshot of whatever the port happened to produce: it is
# 1.3's observed behaviour, and a diff here is a regression against 1.3.
# Deterministic across runs and locale-independent -- both measured.
#
#
# The FITNESS SORT block pins SIG_IndividualListItem::key()'s exponent branch.
# The values are the ones the 1.3 oracle read off the running binary, and 1.3
# sorts the e-05 group first. The port did NOT, until C9: Qt 2's truncate()
# took a uint, so truncate(-1) was a harmless no-op, while Qt 6's takes a
# signed qsizetype and CLEARS the string -- wiping the mantissa of every value
# without an exponent and giving it an all-zero key. Same source, opposite
# behaviour, in code the port never edited.
#
