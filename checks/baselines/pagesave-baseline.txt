# pagesave-baseline.txt -- the widget-to-file path, PORTING.md §9 item 1.
#
# WHAT THIS PINS.
# `pages' proves typing reaches the widgets. `exportall' proves widgets reach a
# file, in one direction, for the export formats. NEITHER covers
# putAllIntoExperiment(): a regression between what a page holds and what
# `File > Save Experiment' writes would have been caught by nothing.
#
# The BASE block below is the port's own save of twoBases.exp: load it, visit
# no View page, change nothing, save once. 178 lines, 1589 bytes. The port's
# save matches 1.3's own byte for byte, compared on twoBasesSimpleFitness2.exp
# against a capture from the 2003 i386 binary (192 lines, 2069 bytes, sha256
# a327150ccf498d57cead7a5d745670999b499a26b398e07335c20e8ee94d7197, with a
# positive control: a second save after changing one visible parameter differs
# in exactly one line). So the block below is the port against itself, on
# proven ground.
#
# The EDITED block is the base plus C11a's eleven page edits. C11a measured
# those typed values identical on both architectures. The whole edited file
# differs from the base in exactly twelve lines and no others: eight typed values, the
# DYNAMECHSINTEGRATOR and fitness-name combos each moving down one item, the
# mutation/reproduction interlock pair (250 + 670 + 80 = 1000), and
# LanguageParameters. 8 + 2 + 2 = 12. *An earlier version said "nine typed
# values" and then listed the fitness-name combo separately, which counted the
# integrator combo as typed and made the arithmetic work only by accident.*
#
# LanguageParameters IS NOT IN THE BLOCK. It lives at line 71650 of the saved
# file, far below `POPULATION BEGIN{' at 179, so a check over the 178-line
# block alone covers eleven of the twelve edits and silently misses the
# registers one. It gets its own line here. That was found because the oracle
# reported where POPULATION BEGIN{ had moved to, not by reading the code.
#
# Two parsing hazards, both real in this data and both reasons the comparison
# is raw bytes rather than key/value pairs: FLOORPICTUREFILE and TEXTUREFILE
# each have an EMPTY value line after them, so anything that skips blank lines
# consumes the next key as a value; and the block ends with a blank line.
# The host line and the two output directories are kept verbatim on save.
#
# Regenerate with:
#   SIGEL_ROOT=sigelApp SIGEL_EXP=... build/guidrive pagesave
#   SIGEL_PAGEEDIT=1 ... build/guidrive pagesave
# and take everything before POPULATION BEGIN{ from each written file.
