# orders and nothing else:

#   B = MUL CMP MOVE COPY LOAD SENSE DIV SUB ADD DELAY MIN MAX MOD
# twoBases A->B, octopusNice A->B, octopusSimple B->A, walker B->A. The two
# octopus files are the same robot shipped in opposite orders -- each one's
# input is the other's output, across every container. Applying the transform
# twice returns the original, which is what bucket reversal on prepend
# predicts, so this is positive evidence for the model rather than mere
# consistency with it.
